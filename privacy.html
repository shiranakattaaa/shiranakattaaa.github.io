プライバシーポリシー（shorts-auto）

制定日：2026年10月6日 ／ 改定日：2026年10月7日

shorts-auto（以下「本アプリ」）は、「知らなかったch」の運営者が、自分自身の YouTube・TikTok・Instagram アカウントに動画を投稿するためだけに使用する個人用ツールです。

1. 取得する情報

本アプリは、各サービスへのログイン時に、動画の投稿に必要な権限のみを取得します。

  • Google（YouTube）：動画のアップロード権限（https://www.googleapis.com/auth/youtube.upload）
  • TikTok：基本的なアカウント情報の参照（user.info.basic）、動画の投稿（video.upload、video.publish）

氏名、メールアドレス、連絡先、視聴履歴などの個人情報を収集・保存することはありません。

2. 利用目的

取得した権限は、運営者自身が作成した動画を、運営者自身のアカウントへ投稿する目的にのみ使用します。

3. 保存と管理

認証情報（アクセストークン）は運営者のパソコン内にのみ保存し、外部のサーバーへ送信・保存することはありません。

4. 第三者への提供

取得した情報を第三者に提供・販売・共有することはありません。

5. Google API サービスの利用について

本アプリによる Google API から取得した情報の使用は、「Google API サービスのユーザーデータに関するポリシー」に従います。限定使用の要件も遵守します。

6. 権限の取り消し

  • Google：Googleアカウントの「サードパーティ製のアプリとサービス」からいつでも取り消せます。
  • TikTok：TikTok アプリの「設定とプライバシー」→「セキュリティ」→「アプリとサービスの権限」からいつでも解除できます。

7. お問い合わせ

YouTube チャンネル「知らなかったch」の概要欄に記載の連絡先までお願いします。

Privacy Policy (English summary)

shorts-auto is a personal tool used only by the owner of the "知らなかったch" channel to upload their own videos to their own YouTube, TikTok and Instagram accounts. It only requests the permissions needed to upload videos (Google: youtube.upload; TikTok: user.info.basic, video.upload, video.publish). It does not collect or store personal information such as names, emails or viewing history. Access tokens are stored only on the owner's computer and are never sent to any other server or shared with third parties. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time from the Google account connections page or the TikTok app settings.
